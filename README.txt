ENRICO MAYHEW — RESUME WEBSITE
================================

Preview:
- Open index.html in a browser.

Publish with GitHub Pages:
1. Create a public GitHub repository (e.g. enrico-resume).
2. Upload index.html to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose the main branch and / (root), then Save.
6. GitHub will provide your public website URL.

Before publishing:
- Replace YOUR.EMAIL@example.com in index.html with the email address you want public.
- Check that every listed responsibility matches your actual job.
- Add any real achievements or measurable results you want to feature.
- This is an original design inspired by dark London nightlife visuals; it does not use Circuit's logos or proprietary assets.
